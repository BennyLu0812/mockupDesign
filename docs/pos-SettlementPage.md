# 概覽 
前台销售(POS)
POS提供给各實體書店、銷售點或代售點使用，可以處理多個銷售點或多個櫃運作。要求前台系統可以在線(有線或無線網)運作，進行結帳收款及打印相關單據:開發票、開收據、開臨時收據、開送貨單和開報價單。
系統可記録每一收銀錢箱的現金結餘,支付情況等資料及員工銷售的金額 資料(按日、月、年或翰入的起止日期查詢)。
根據本局的業務財務規定，系統可處理線上及線下的銷售交易的退款，包括但不限於支援原路退款、支票方式退款、財政局退款、部分退款等操作。

# 核心功能
## 1.結賬頁面
- 結賬頁面，佈局時按左右結構，左邊是購物車，右面是印刷品展示。點擊印刷品能將印刷品放到左邊的購物車中。
- 有結算按鈕和掛單按鈕，點擊結算時，能打算支付界面。支付界面支持現金結算和電子支付。電子支付時可以選擇政付通平台、銀行智慧支付、信用卡支付、其他。
- 左邊購物車占佈局的1/4,其他都是印刷品展示
- 印刷品分類有：法律，政治及公共行政，經濟，教育，歷史文化，文學，藝術，科學，綜合
- 印刷品展示需要展示中文和葡文名稱、出版機構、封面、出版日期、語言、單價
- 印刷品展示中能按照分類，名稱，編碼查詢
- 購物車表格的列寬度分配，讓商品名稱更寬，數量列更窄
- 印刷品展示從表格改為卡片網格佈局，呈現正方塊效果
