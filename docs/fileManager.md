# 概覽
法律統一平台的文件管理

# 菜單
法律統一平台
├── 文件庫管理
├── 文件夾管理
├── 文件管理
# 核心功能
## 1.新增文件庫管理
- 文件庫管理
1、支持文件庫的增刪改查
2、支持查看文件庫的詳情，及文件庫內文件夾內的文件信息
- 文件庫分權分域
1、作為統一平台，文件庫會有不同部門在此進行應用。
2、需要支持文件庫的權限進行劃分，以部門作為單位，當前部門只能看到當前的權限數據
- 文件庫屬性自定義配置
1、支持配置文件庫的標籤、以及文件庫的自定義字段，及字段的前端展示。每個文件庫都有自己的不同字段信息。
2、但是需要包括最為資本的名稱、建立時間、更新時間等字段。

## 2.新增文件夾管理
- 文件夾管理		
1、支持文件夾的增刪改查
2、支持查看文件夾的詳情，及文件夾內的文件信息
- 文件夾權限管理		
1、支持對當前系統的角色人員，劃分不同的文件夾權限。
2、文件夾和角色之前的關係是多對多，即一個角色可以查看多個文件夾，一個文件夾擁有多個角色。
3、相關文件夾權限需要嚴格查詢、上傳、下載、預覽、遷移等劃分（需要詳細的操作權限劃分）
- 文件夾標籤		
支持定義文件夾相關標籤，標識文件夾的作用
- 文件夾歷史記錄		
支持查看所有關於文件夾的操作歷史記錄，包含對文件夾的增刪改記錄
- 文件夾用戶查看		
支持查看文件夾內用戶數據，且能對用戶進行新增和移除
- 文件夾遷移		

## 3.新增文件管理
- 文件上傳及管理
1、文件增刪改：支持對文件的新增、刪除、編輯
2、文件規範化名稱：提供結構化規範化的表單，完成㐉文件版本、來源、日期、相關項目的錄入
3、本地上傳：支持通過本地對文件進行上傳
4、掃描上傳：需要對接相關掃描系統，完成對文件從掃描平台的獲取
- 文件軟刪除/硬刪除
1）文件上傳之後，應該在系統內永久存儲。文件支持軟刪除（一般的刪除），硬刪除（需要高級權限）
2）文件刪除之後進入到軟刪除區（類似回收站的地方，軟刪除的文件前端不可見。但是支持高級權限人員去恢復文件）
3）硬刪除文件，只能是高級權限人員才能操作，需要高風險提醒。
- 文件屬性標籤自定義
1、支持自定義文件屬性，如出街/不出街/已公佈/過度文件作為區分
2、屬性可以是時間、字符串、或者自定義的唯一編號格式
- 文件格式支持
1、在系統裏面支持對相關多種格式文件（PDF、DOC、TIFF、EXCEL、JPG、video、voice）做預覽。
2、windows系統常用音頻格式支持，視頻格式支持
- 文件預覽
需要對系統支持的多樣文件做預覽（文件查看、音頻播放、視頻播放等）
- 文件預覽下載權限		
文件的預覽、下載、列印都需要單獨的權限控制
- 文件列印		
需要支持對文件的列印
- 文件變更記錄		
需要記錄所有文件的變更記錄。（如上傳文件、查看文件、下載文件、文件改名、文件遷移等信息。詳細到時分秒和操作人員）
- 文件批量操作		
支持對文件的批量上傳、刪除、修改名稱、修改標籤等
- 文件編輯調用本地WORD		
1、支持對文件編輯的時候直接調用本地WORD進行WORD文檔編輯
2、需要支持保存本地WORD之後，自動上傳一個新的版本完成附件的上傳
