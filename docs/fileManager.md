# 概覽
法律統一平台的文件管理

# 菜單
法律統一平台
├── 文件庫管理
├── 文件夾管理

# 核心功能
## 1.新增文件庫管理
- 文件庫管理
1、支持文件庫的增刪改查
2、支持查看文件庫的詳情，及文件庫內文件夾內的文件信息
- 文件庫分權分域
1、作為統一平台，文件庫會有不同部門在此進行應用。
2、需要支持文件庫的權限進行劃分，以部門作為單位，當前部門只能看到當前的權限數據
- 文件庫屬性自定義配置
1、支持配置文件庫的標籤、以及文件庫的自定義字段，及字段的前端展示。每個文件庫都有自己的不同字段信息。
2、但是需要包括最為資本的名稱、建立時間、更新時間等字段。

## 2.新增文件夾管理
- 文件夾管理		
1、支持文件夾的增刪改查
2、支持查看文件夾的詳情，及文件夾內的文件信息
- 文件夾權限管理		
1、支持對當前系統的角色人員，劃分不同的文件夾權限。
2、文件夾和角色之前的關係是多對多，即一個角色可以查看多個文件夾，一個文件夾擁有多個角色。
3、相關文件夾權限需要嚴格查詢、上傳、下載、預覽、遷移等劃分（需要詳細的操作權限劃分）
- 文件夾標籤		
支持定義文件夾相關標籤，標識文件夾的作用
- 文件夾歷史記錄		
支持查看所有關於文件夾的操作歷史記錄，包含對文件夾的增刪改記錄
- 文件夾用戶查看		
支持查看文件夾內用戶數據，且能對用戶進行新增和移除
- 文件夾遷移		
支持將一個文件夾內的全部（部分）文件遷移到另一個文件夾
