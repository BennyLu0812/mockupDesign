# 核心功能
## 1.新增任務界面
这是一个新建任务的页面，从布局和功能点来看：
- 中间区域：
有項目名稱输入框，可用于填写任务标题。
下方是一个带有丰富编辑功能的文本编辑区域，包含字体样式（如加粗、斜体、下划线等）、排版格式（如有序列表、无序列表等）以及支持 Markdown 格式等功能，方便详细描述任务内容。
- 右侧区域： 
1、基础字段：可以选择項目類型（一般項目、法案項目、其他）、項目狀態（進行中、已完成、已取消）、項目開始時間、項目結束時間、項目參與人員（陳大文、張三、李四）、項目備註信息、項目到期時間 ，这些信息有助于明确任务的基本属性和时间安排。佈局時字段與值按左右結構佈局。
2、工时：可以预估完成任务所需的工时。
3、附件：提供了添加附件的功能，可上传与任务相关的文件资料。支持常見WORD、EXCEL、音視頻等多媒體文件上傳。
- 左下角区域：
有关联项相关内容，目前显示关联项数量为 0，可能用于关联其他相关的工作项，并且有相关提示说明添加自动化规则的作用。
- 区域之間用細線分隔，保存按鈕、取消按鈕左右佈局。頁面整體佈局精美一些。

## 2.新增工作流配置頁面
一、主工作流配置页面
- 布局
顶部：右上角有蓝色的 “添加工作项状态” 按钮。
左侧：为工作流状态列表，包含 “待处理（默认）”“处理中”“已完成（正常结束）”“已取消（异常结束）” 等状态，每个状态前有可拖动的图标用于调整顺序。
中间及右侧：为状态转换矩阵，以表格形式呈现各状态间的转换关系，行表示当前状态，列表示目标状态。
底部：为 “关系对象流转规则” 区域，用于配置与其他对象相关的流转规则。
- 颜色
“添加工作项状态” 按钮为蓝色，文字为白色。
状态名称背景色：“待处理” 为蓝色，“处理中” 为绿色，“已完成” 和 “已取消” 为灰色，文字均为白色。
复选框选中时为蓝色，未选中或禁用时为灰色。
提示框背景为黑色，文字为白色。
- 能效果
状态管理：可通过 “添加工作项状态” 按钮添加新状态，拖动状态左侧图标调整顺序，鼠标悬停在状态上显示 “删除步骤” 提示可删除状态。
状态转换配置：通过复选框启用或禁用状态转换，点击加号图标显示 “新增规则” 提示可添加转换规则。
关系对象流转规则：点击加号图标可添加相关规则，鼠标悬停在问号图标上显示规则说明，如 “子全部完成父才置为完成”。
二、“添加工作项状态” 弹出窗口,彈出效果為由右邊向左邊的展示頁面。
- 布局
顶部：标题为 “添加工作项状态”。
中部：包含 “状态名称” 标签和下拉选择框，下拉选择框展开后有搜索框和状态选项列表，列表中状态按分类显示。下方有 “任何状态都可以流转到该状态” 的开关按钮。
底部：有 “取消” 和 “确定” 按钮。
- 颜色
窗口标题文字为黑色。
下拉选择框默认文字为灰色，展开后搜索框边框为灰色，状态选项文字为黑色，分类标签为蓝色。
开关按钮开启时为蓝色，关闭时为灰色。
“取消” 按钮为灰色，“确定” 按钮为蓝色，文字均为白色。
- 功能效果
状态选择：可通过下拉选择框选择现有状态，或在搜索框中搜索状态，若未找到可点击 “去新建” 链接创建新状态。
流转设置：通过开关按钮设置是否允许任何状态流转到该状态。
操作确认：点击 “确定” 按钮确认添加，点击 “取消” 按钮取消添加。
三、“新建步骤流转规则” 弹出窗口,彈出效果為由右邊向左邊的展示頁面。
- 布局
顶部：标题为 “新建步骤流转规则”。
中部：显示规则触发条件和具体条件，包括 “字段 必填”“由 部分人 操作”“且 字段 包含 目标值” 等，还有 “字段条件” 链接。
底部：有 “取消” 和 “新建” 按钮。
- 颜色
窗口标题文字为黑色。
状态名称背景色：“处理中” 为绿色，“待处理” 为蓝色，文字均为白色。
条件文字为黑色，“字段条件” 链接为蓝色。
“取消” 按钮为灰色，“新建” 按钮为蓝色，文字均为白色。
- 功能效果
规则配置：设置工作项状态转换的触发条件和具体条件，如字段必填、操作权限、字段值条件等，可通过 “字段条件” 链接添加更多条件。
操作确认：点击 “新建” 按钮保存规则，点击 “取消” 按钮取消配置。
四、“新建流转限制” 弹出窗口,彈出效果為由右邊向左邊的展示頁面。
布局
顶部：标题为 “新建流转限制”。
中部：显示规则触发条件和具体条件，即 “全部 子关系 工作项 为 状态”，还有 “条件” 链接。
底部：有 “清空”“取消” 和 “新建” 按钮。
颜色
窗口标题文字为黑色。
状态名称背景色：“待处理” 为蓝色，文字为白色。
条件文字为黑色，“条件” 链接为蓝色。
“清空”“取消” 按钮为灰色，“新建” 按钮为蓝色，文字均为白色。
功能效果
规则配置：设置工作项状态转换的触发条件和子关系条件，可通过 “条件” 链接添加更多条件。
操作确认：点击 “新建” 按钮保存规则，点击 “取消” 按钮取消配置，点击 “清空” 按钮清除当前配置。

## 3.新增任務查詢界面
- 分頁展示所有任務記録， 顯示標題，裝填，負責人，創建者，創建時間，項目類型，優先級，操作（詳情，刪除）
- 支持通過項目名稱、項目狀態、項目編號、項目開始和結束日期來篩選結果
- 列表有詳情按鈕，點擊按鈕顯示任務記録，顯示效果由右邊向左展示界面，界面內容和佈局可以參考“新增任務界面”的佈局和內容，將值帶入相應欄位。
- 有新增任務按鈕。點擊新增按鈕時，由右邊向左邊展示“新增任務界面”
- 刪除單個項目，不支持批量刪除。
1、進行中的項目不允許刪除，只能走流程取消或完結
2、預備中的項目可以允許刪除
3、被關聯或引用的項目不允許刪除
