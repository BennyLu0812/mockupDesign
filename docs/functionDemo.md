# 概覽
新增一個功能界面

# 核心功能
## 1.页面整体架构
采用 “顶部操作栏 + 左侧导航 + 主编辑区 + 右侧实时预览” 的四栏布局，确保编辑与预览同步，格式实时校验。
区域	功能描述
顶部操作栏	存储 / 保存、导出（Word/PDF）、版本管理、格式校验等全局操作按钮
左侧导航	法案结构导航（基础信息、章节条款、废止部分、生效与签署信息），支持快速跳转
主编辑区	动态表单 + 富文本编辑，按模块展示可编辑字段，支持条款动态增删
右侧实时预览	实时渲染当前编辑内容，与最终文档格式一致，直观展示排版效果
 

## 2.顶部操作栏详细设计
基础操作：
「保存」按钮：实时保存编辑内容（自动触发格式校验，提示未填必填项）。
「导出」下拉菜单：支持导出为 “Word（.docx）”“PDF” 格式，导出前自动校验格式合规性（如条款编号连续性、签署日期完整性）。
版本管理：
「版本历史」按钮：弹出侧边栏显示所有修改版本（含版本号、修改人、时间、修改说明），支持 “查看差异”“回滚到该版本”。
「提交审核」按钮：针对定稿内容发起审核流程（状态同步显示为 “待审核 / 已通过 / 已驳回”）。

## 3.左侧导航详细设计
以模板层级为基础，拆解为 4 个核心模块，点击导航项可快速跳转至对应编辑区：
「基础信息」：法案编号、名称、立法依据等顶层信息。
「章节条款」：编、章、节、条的动态管理（核心编辑区）。
「废止部分」：需废止的法律法规列表。
「生效与签署」：生效日期、立法会 / 行政长官签署信息。

## 4.主编辑区详细设计
按左侧导航模块拆分，每个模块采用 “固定字段 + 动态表单” 结合的方式，确保格式统一。
（1）基础信息模块
	字段名称	组件类型	说明
	法律编号	文本框	格式示例：“第 XX/20xx 號”，自动校验 “/” 前后数字格式
	法律名称	文本框	如 “XXXXXX”，支持字数限制（最多 50 字）
	立法依据	富文本编辑器	需引用《基本法》等条款（支持加粗法规名称、自动补全引号，如 “《澳门特别行政区基本法》”）
	立法目的	富文本编辑器	支持分点描述（自动生成 “一、二、三” 列表，符合法律文书格式）
（2）章节条款模块（核心动态表单区）
层级管理组件：
	顶部设「添加编」「添加章」「添加节」按钮（按模板层级限制顺序，如 “章” 需隶属于 “编”，不可跨级添加）。
	每个层级下显示对应标题输入框（如 “编名称：”“章名称：”），输入后自动生成编号（如输入 “总则” 自动补全为 “第一编 总则”）。
条款动态表单（核心）：
	每个 “条” 通过「添加条款」按钮生成，包含：
	条编号：自动生成（如 “第一条”“第二条”，删除中间条款后自动重排编号）。
	条标题：文本框（如 “標的”“廢止”）。
	条内容：富文本编辑器（支持多级列表：“一、二、三”“（一）（二）（三）”“（1）（2）（3）”，自动对齐缩进，且符号格式固定不可修改）。
	操作按钮：「添加子项」（用于嵌套 “款 / 项”）、「删除条款」（删除后触发编号重排）。
（3）废止部分模块
「添加废止项」按钮：点击后生成一行表单，包含：
	法规类型：下拉选择（“法律”“法令”“行政法規”“訓令” 等，对应模板中的 “第 XX/XX/M 號法律”“第 XX/XXXX 號行政法規”）。
	法规编号：文本框（如 “XX/XX/M 號”“XX/XXXX 號”）。
	法规名称：文本框（需包裹书名号《》，自动补全格式）。
	颁布日期：日期选择器（如 “XX 月 XX 日”）。
列表展示：所有废止项以序号（“（一）（二）...（十）”）自动排序，删除项后序号自动重排。
（4）生效与签署信息模块
	生效日期：日期选择器（对应 “本法律自 ------ 選擇生效日期 ------ 起生效”），选择后自动填充为 “二零 XX 年 XX 月 XX 日” 格式。
	立法会签署：
	通过日期：日期选择器（对应 “二零 ----- 選擇年 ----- 年... 通過”）。
	签署人：文本框（默认填充 “高開賢”，可修改），输入后自动关联 “立法會主席” 前缀。
	行政长官签署：
	签署日期：日期选择器（对应 “二零 ----- 選擇年 ----- 年... 簽署”）。
	签署人：文本框（默认填充 “岑浩輝”，可修改），输入后自动关联 “行政長官” 前缀。

  ## 5.右侧实时预览区详细设计
	功能：实时同步主编辑区内容，按模板格式渲染（字体、字号、行间距、编号格式与最终文档一致）。
	交互：
	点击预览区内容，自动定位到主编辑区对应编辑项（便于快速修改）。
	支持 “缩小 / 放大” 预览比例，底部显示页码（按 A4 纸排版计算）。
	格式校验提示：若内容不符合模板格式（如条款子项符号错误、日期格式错误），预览区对应位置标红，并显示提示（如 “子项符号应为（一），请修改”）

  ## 6.关键交互设计
格式强制约束：
富文本编辑器仅开放模板允许的格式（如固定列表符号、缩进距离），禁用自定义字体 / 颜色（确保与模板一致）。
日期、编号等字段输入后自动格式化（如输入 “20241001” 自动转换为 “二零二四年十月一日”）。
操作反馈：
新增 / 删除条款时，底部弹出提示 “已添加第 X 条”“已删除第 X 条，编号已重排”。
保存成功后显示 “内容已保存至版本 V2.1”，失败时提示具体错误（如 “立法依据未填写，请补充”）。
历史追溯：
预览区支持切换历史版本对比（左侧当前版，右侧历史版，差异内容标黄）。
每条修改记录关联操作人（如 “2024-10-01 张三 修改了第一条内容”）。
